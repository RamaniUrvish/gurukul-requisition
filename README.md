# Requisition Maker · Gurukul USA

The members' page for Gurukul USA reimbursement requisitions. Members sign in with the username and
password their admin gives them. All vouchers, receipts and accounts are stored privately in Gurukul's
Google account; this repository holds only the page itself.

Built from `google-app/` (see `build_web.py` there). Do not edit `index.html` by hand.
